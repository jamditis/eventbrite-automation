01 — How it works

Five steps from submission to draft

01

Form submitted

Someone fills out the Airtable event request form with all event details.

02

Webhook triggered

Airtable automation detects the new record and sends a webhook to our server.

03

Image generated

Gemini AI creates a professional 2048×1024 banner image with event title.

04

Draft created

Full Eventbrite listing created with image, description, tickets, and venue.

05

Status updated

Airtable record marked as processed. Draft ready for review in Eventbrite.

02 — Setup guide

Deploy to Raspberry Pi

SSH into your Raspberry Pi and clone the repository from GitHub.

# SSH to your Pi ssh pi@raspberrypi.local # Clone the repository cd /home/pi git clone https://github.com/jamditis/eventbrite-automation.git cd eventbrite-automation

The setup script creates the virtual environment, installs dependencies, and configures the systemd service.

# Make script executable and run chmod +x deploy/setup.sh ./deploy/setup.sh

Create a .env file with your API credentials:

Variable Description
AIRTABLE_PAT Airtable Personal Access Token
AIRTABLE_BASE_ID Base ID (starts with app...)
AIRTABLE_TABLE_ID Table ID (starts with tbl...)
GEMINI_API_KEY Google Gemini API key
EVENTBRITE_PRIVATE_TOKEN Eventbrite private OAuth token

Enable and start the webhook server as a system service:

# Enable auto-start on boot sudo systemctl enable eventbrite-automation # Start the service sudo systemctl start eventbrite-automation # Check status sudo systemctl status eventbrite-automation

Install ngrok to expose your local server to the internet:

# Install ngrok curl -s https://ngrok-agent.s3.amazonaws.com/ngrok.asc | \ sudo tee /etc/apt/trusted.gpg.d/ngrok.asc >/dev/null echo "deb https://ngrok-agent.s3.amazonaws.com buster main" | \ sudo tee /etc/apt/sources.list.d/ngrok.list sudo apt update && sudo apt install ngrok # Authenticate with your ngrok token ngrok config add-authtoken YOUR_TOKEN # Start the tunnel ngrok http 5000

Copy the HTTPS URL and use it in your Airtable automation webhook.

Create an Airtable automation that triggers when a new record is created:

  1. Go to Automations → Create automation
  2. Trigger: "When a record matches conditions"
  3. Condition: Status is empty OR Status is "Todo"
  4. Action: "Send a webhook" with POST method
{ "record_id": "{RECORD_ID()}" }
03 — API endpoints

Webhook server reference

GET /

Health check

Returns server status. Use this to verify the webhook server is running.

curl http://localhost:5000/
POST /webhook/airtable

Process single record

Process a specific Airtable record by its ID. This is what Airtable calls.

curl -X POST http://localhost:5000/webhook/airtable \ -H "Content-Type: application/json" \ -d '{"record_id": "recXXXXXXXX"}'
POST /webhook/airtable

Process all unprocessed

Batch process all records that haven't been processed yet.

curl -X POST http://localhost:5000/webhook/airtable \ -H "Content-Type: application/json" \ -d '{"action": "process_all"}'
GET /webhook/test

Test endpoint

Simple test endpoint to verify webhook connectivity without processing.

curl http://localhost:5000/webhook/test
04 — Troubleshooting

Common issues and fixes

Event didn't appear in Eventbrite

Check that the event date is in the future — Eventbrite won't create events with past dates. Also verify all required fields are filled in Airtable.

Image looks wrong

AI does its best, but sometimes the generated image needs a redo. You can upload a different image manually in the Eventbrite dashboard.

Service won't start

Run journalctl -u eventbrite-automation -n 50 to see error logs. Common causes: missing .env file, dependencies not installed, or wrong paths.

Webhook not receiving requests

Verify ngrok tunnel is running. Check that the URL in Airtable automation matches your ngrok URL exactly. Test with curl from another machine.

Airtable 403 error

Your Personal Access Token doesn't have access to this base. Generate a new PAT at airtable.com/create/tokens with the correct base permissions.

Virtual events missing Zoom link

Zoom links must be added manually. Go to Eventbrite → Edit event → Online event page → Add Zoom or Link another provider.
